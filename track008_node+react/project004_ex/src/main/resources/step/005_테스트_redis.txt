## 🔎1. Redis 설치
Windows용 Redis 포트 설치: MicrosoftArchive Redis for Windows에서 MSI 설치 파일 다운로드 후 실행.
설치 후 redis-server.exe 실행 → 6379 포트에서 Redis 실행됨.
이렇게 하면 Docker 없이도 Redis를 바로 사용할 수 있습니다.

https://github.com/microsoftarchive/redis/releases

## 🔎2.  Redis 실행 방법 (Windows MSI 설치 후)

1. **설치 위치 확인**
   - 기본적으로 `C:\Program Files\Redis` 또는 `C:\Program Files (x86)\Redis` 폴더에 설치됩니다.
   - 그 안에 `redis-server.exe`와 `redis-cli.exe` 파일이 있습니다.

2. **Redis 서버 실행**
   - 명령 프롬프트(CMD) 또는 PowerShell을 열고 설치 경로로 이동:
     ```powershell
     cd "C:\Program Files\Redis"
     ```
   - Redis 서버 실행:
     ```powershell
     redis-server.exe
     ```
   - 실행되면 콘솔에 로그가 뜨고, 기본 포트 `6379`에서 Redis 서버가 대[기합니다.

3. **Redis 클라이언트 접속 (테스트)**
   - 새 CMD/PowerShell 창을 열고 같은 경로에서:
     ```powershell
     redis-cli.exe
     ```
   - 접속 후 `ping` 입력 → 응답으로 `PONG`이 나오면 정상 실행된 겁니다.

4. **Windows 서비스로 등록 (자동 실행)**
   - 설치 시 서비스 등록 옵션을 선택했다면, Redis가 Windows 서비스로 자동 실행됩니다.
   - 확인 방법:
     ```powershell
     services.msc
     ```
     → 서비스 목록에서 `Redis` 확인 후 실행 상태 체크.
   - 서비스가 꺼져 있으면 수동으로 시작할 수 있습니다.

---

## ✨ 정리
- `redis-server.exe` 실행 → Redis 서버 시작  
- `redis-cli.exe` 실행 → 클라이언트 접속 및 테스트 (`ping` → `PONG`)  
- 서비스로 등록하면 Windows 부팅 시 자동 실행도 가능합니다
