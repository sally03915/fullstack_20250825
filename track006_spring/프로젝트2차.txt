## 📑 프로젝트 진행 순서 (Project Flow)

> 발표 : 12월 8일


### 1. 프로젝트 개요 (Introduction)
- **배경**: 기존 게시판의 단순 CRUD 기능 한계를 극복하고, 
           사용자 경험과 유지보수성을 강화하기 위해 Spring, MyBatis, JSTL, AJAX 기반 업그레이드 진행  
- **목적**: 안정적 구조 설계, 효율적 DB 연동, 직관적 뷰 구현, 비동기 처리로 UX 개선  
- **주요 기능**: 회원 관리, 게시글 CRUD, 댓글/대댓글, 검색·페이징, 좋아요·조회수, 관리자 페이지  
- **기대 효과**: 실무형 풀스택 역량 강화, 통합 기술 활용 능력 습득, 클린 아키텍처 경험, 사용자 친화적 UI/UX 제공  

---

### 2. 주요 기능 (CRUD 중심)
#### 2-1. 멤버 관리
| 구분 | 사용자 측 | 관리자 측 |
|------|-----------|-----------|
| CREATE | 회원가입 | 회원가입 |
| READ | 로그인, 아이디/비밀번호 찾기, 마이페이지 조회 | 전체 유저 정보 확인 |
| UPDATE | 정보 수정 | 회원 정보 수정 |
| DELETE | 회원 탈퇴 | 회원 탈퇴 |

#### 2-2. 게시판 관리
| 구분 | 사용자 측 | 관리자 측 |
|------|-----------|-----------|
| CREATE | X | 게시글 작성 |
| READ | 전체 글 조회, 상세 조회 | 전체 글 조회, 상세 조회 |
| UPDATE | X | 글 수정 |
| DELETE | X | 글 삭제 |

---

### 3. 시스템 흐름도 (Flow Diagram)
- **사용자(User)**  
  - 회원가입 → DB 저장  
  - 로그인/아이디·비밀번호 찾기 → 마이페이지 조회  
  - 정보 수정 → DB 업데이트  
  - 탈퇴 → DB 삭제  

- **관리자(Admin)**  
  - 회원가입 → DB 저장  
  - 전체 유저 정보 확인 → DB 조회  
  - 회원 정보 수정 → DB 업데이트  
  - 회원 탈퇴 → DB 삭제

### 5. 데이터베이스 설계 (ERD)

### 6. 구현 단계 (Implementation)
- **회원 관리 모듈**: 가입, 로그인, 인증, 마이페이지  
- **게시판 모듈**: 글 작성/수정/삭제, 댓글·대댓글
- **검색 및 페이징 모듈**: 동적 SQL 기반  
- **관리자 모듈**: 회원 관리, 게시글 관리  
- **AJAX 적용**: 실시간 검색 등 실시간 반영
